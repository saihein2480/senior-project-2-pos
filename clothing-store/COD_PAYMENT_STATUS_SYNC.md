# COD Payment Status Synchronization

## Issue
When the owner marks a COD order as "Paid" in the online orders page (`/owner/sales/online-orders`), the payment status was not updating in the customer's purchases page (`/account/purchases`).

## Root Cause
The `updateOnlineOrderPaymentStatus` function was trying to find the transaction document using the `orderId` as the document ID:
```typescript
const transactionRef = doc(db, "transactions", orderId); // ❌ Wrong
```

However, COD transactions are stored with **Firestore auto-generated document IDs**, not the `orderId` as the document ID. The `orderId` is stored as a **field** within the document.

## Solution
Changed the function to **query** the transactions collection by the `transactionId` field instead of directly accessing by document ID.

## Changes Made

### File: `pos-clothing-store/clothing-store/src/services/onlineOrderService.ts`

#### 1. Added Import
```typescript
import {
  collection,
  doc,
  getDoc,
  getDocs,
  orderBy,
  query,
  updateDoc,
  where,        // ✅ ADDED
  writeBatch,
} from "firebase/firestore";
```

#### 2. Updated Query Logic

**Before (Incorrect):**
```typescript
// Tried to find transaction by document ID
const transactionRef = doc(db, "transactions", orderId);
const txSnap = await getDoc(transactionRef);

if (txSnap.exists()) {
  await updateDoc(transactionRef, {
    status: txStatus,
    paymentStatus,
    updatedAt: new Date().toISOString(),
  });
}
```

**After (Correct):**
```typescript
// Query transactions collection to find matching transactionId
const transactionsRef = collection(db, "transactions");
const q = query(transactionsRef, where("transactionId", "==", orderId));
const querySnapshot = await getDocs(q);

if (!querySnapshot.empty) {
  // Update the first matching transaction
  const transactionDoc = querySnapshot.docs[0];
  await updateDoc(doc(db, "transactions", transactionDoc.id), {
    status: txStatus,
    paymentStatus,
    updatedAt: new Date().toISOString(),
  });
}
```

## How It Works

### Workflow:

1. **Owner marks COD as paid** in `/owner/sales/online-orders`
2. **Updates online order** payment status to "SUCCESS"
3. **Queries transactions** collection for matching `transactionId`
4. **Updates transaction** with:
   - `status`: "completed"
   - `paymentStatus`: "SUCCESS"
   - `updatedAt`: current timestamp
5. **Customer sees update** in `/account/purchases` immediately

### Database Structure:

#### onlineOrders Collection:
```javascript
// Document ID: "TXN-0000000000065"
{
  orderId: "TXN-0000000000065",
  transactionId: "TXN-0000000000065",
  paymentMethod: "cod",
  paymentStatus: "PENDING", // Changes to "SUCCESS"
  status: "delivered",
  // ... other fields
}
```

#### transactions Collection:
```javascript
// Document ID: "abc123xyz" (auto-generated by Firestore)
{
  transactionId: "TXN-0000000000065",  // ← Query by this field
  onlineOrderId: "TXN-0000000000065",
  paymentMethod: "cod",
  status: "pending",           // Changes to "completed"
  paymentStatus: "PENDING",    // Changes to "SUCCESS" ✅
  customerUid: "customer-uid",
  // ... other fields
}
```

### Query Explanation:

```typescript
// Build query to find transaction
const q = query(
  collection(db, "transactions"),           // In transactions collection
  where("transactionId", "==", orderId)     // Where transactionId matches orderId
);

// Execute query
const querySnapshot = await getDocs(q);

// Get the document
if (!querySnapshot.empty) {
  const transactionDoc = querySnapshot.docs[0];  // First (and should be only) match
  const docId = transactionDoc.id;               // e.g., "abc123xyz"
  
  // Update using the actual document ID
  await updateDoc(doc(db, "transactions", docId), {
    status: "completed",
    paymentStatus: "SUCCESS",
    updatedAt: new Date().toISOString(),
  });
}
```

## Status Mapping

When marking COD as paid:

| Online Order Field | Value     | Transaction Field | Value       |
|-------------------|-----------|-------------------|-------------|
| paymentStatus     | "SUCCESS" | paymentStatus     | "SUCCESS"   |
| status            | (unchanged) | status          | "completed" |

### Payment Status Values:
- `"PENDING"` → Customer hasn't paid yet
- `"SUCCESS"` → Customer has paid (COD delivered and paid)

### Transaction Status Values:
- `"pending"` → Order not yet completed
- `"completed"` → Order fulfilled and paid

## Error Handling

The function includes try-catch to handle errors gracefully:

```typescript
try {
  // Query and update transaction
} catch (error) {
  console.error("Failed to update linked COD transaction payment status:", error);
  // Error is logged but doesn't fail the online order update
}
```

### Possible Errors:
1. **Transaction not found**: If query returns no results (shouldn't happen for properly created orders)
2. **Permission denied**: If Firestore rules block the update
3. **Network error**: If connection fails during update

In all cases:
- Online order payment status WILL update (happens first)
- Transaction payment status might NOT update (in error cases)
- Error is logged to console for debugging

## Real-time Updates

### Customer Purchases Page:
The purchases page uses a real-time Firestore listener:
```typescript
onSnapshot(collection(db, "transactions"), (snap) => {
  // Updates automatically when transaction changes
});
```

This means:
- ✅ Payment status updates appear **immediately** without refresh
- ✅ No need to reload the page
- ✅ Real-time synchronization between owner and customer views

### How Fast?
- Update propagation: < 1 second typically
- May take a few seconds on slow connections
- Customer can refresh page if update doesn't appear

### Service Layer:
```typescript
// pos-clothing-store/clothing-store/src/services/onlineOrderService.ts
async updateOnlineOrderPaymentStatus(orderId: string, paymentStatus: string) {
  // 1. Update online order
  await updateDoc(doc(db, "onlineOrders", orderId), {
    paymentStatus,
    updatedAt: new Date().toISOString(),
  });

  // 2. Update linked transaction
  const q = query(
    collection(db, "transactions"),
    where("transactionId", "==", orderId)
  );
  const querySnapshot = await getDocs(q);
  
  if (!querySnapshot.empty) {
    await updateDoc(doc(db, "transactions", querySnapshot.docs[0].id), {
      status: "completed",
      paymentStatus: "SUCCESS",
      updatedAt: new Date().toISOString(),
    });
  }
}
```

## Troubleshooting

### Issue: Payment status not updating for customer

**Check:**
1. Is the online order payment status updated? (Check Firestore console)
2. Is the transaction document updated? (Check Firestore console)
3. Are there any console errors in the owner dashboard?
4. Did the customer refresh their purchases page?

**Solutions:**
- Check browser console for JavaScript errors
- Verify Firestore rules allow updates
- Check network tab for failed requests
- Try marking as paid again

### Issue: Transaction not found

**Possible Causes:**
1. Transaction was created before the `transactionId` field was added
2. `transactionId` value doesn't match `orderId`
3. Transaction was deleted

**Solutions:**
- Check if transaction exists in Firestore console
- Verify `transactionId` field matches `orderId`
- Create a new test order to verify fix works
